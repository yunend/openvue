⚡ OpenVue

A lightweight local HTTP file server based on Tauri 2 + Axum.
One-click launch, plugin extensions, multi-device preview — ready to go.

⬇️ Download Now 🧩 Build Plugins 📦 GitHub

🎯 Core Features

Desktop app + HTTP server dual mode covers various use cases

🚀

One-Click Launch

Install and use immediately. Desktop app supports auto-start. HTTP server + Tauri GUI combine the best of both worlds — desktop control with browser convenience.

🧩

Plugin Extensions

Extend file preview capabilities via HTML pages. Supports GeoGebra, Markdown, Office documents and more. Plugins are customizable, downloadable, and uninstallable.

📂

Directory Browse & File Upload

Browse specified directories in the browser with file upload support. Access from any device on your local network — no extra tools needed.

🌐

Dual Mode

Desktop Mode: Tauri window manages plugins & settings; Server Mode: pure HTTP backend, ideal for server deployment.

🔌

Plugin Marketplace

Built-in plugin marketplace. One-click download & install from remote indexes with auto hash verification. Update or uninstall anytime.

🌍

Internationalization

Built-in bilingual UI (EN/ZH). Both desktop and web pages support language switching to serve users worldwide.

🧩 Plugin Development

An OpenVue plugin is essentially a standard web page (HTML + CSS + JS) that renders files of a specific format. Create your own in just 3 steps!

Create Plugin Directory

Create a folder under plugins/ named after your plugin ID, e.g. my-viewer.

Write index.html

Build a preview page. Use the ?path= parameter to get the file URL, then load and render it.

Add plugin.json

Create plugin.json in the plugin directory to describe the plugin name, supported extensions, download sources, etc.

// plugin.json example { "id": "my-viewer", "name": "My Viewer", "version": "1.0.0", "extensions": ["ext1", "ext2"], "urlTemplate": "/plugins/{pluginId}/?path={publicPath}", "downloadSources": [ { "label": "Github", "url": "https://...", "priority": 1 } ], "sha256": "e261d6162b91991c..." }

💡 When your plugin is ready, package it as a ZIP and submit it along with plugin.json to the openvue-plugins repository — it will be listed in the marketplace.

⚡ Quick Start

Download from Releases to get started, or build from source

📦 Download & Install

  1. Go to Releases and download the latest version
  2. Windows: run the installer; macOS: mount the DMG; Linux: use AppImage
  3. Launch it — manage settings in the desktop app, preview via your browser

🔧 Build from Source

  1. git clone https://github.com/yunend/openvue.git
  2. cd openvue && npm install
  3. cargo tauri dev (dev mode)
  4. cargo tauri build (production build)
